# Existing audio/YouTube-to-chords/sheet-music/tablature implementations (survey as of 2026-10-01)

Scope note: findings below are from web search and page fetches on 2026-10-01. GitHub counts come from the GitHub REST API on that date. Reddit could not be fetched (blocked for the crawler), so community failure-mode reports come from forums, vendor review posts and news articles instead. Where a vendor's own blog is the source, it is flagged.

## Key question 1: Open-source end-to-end projects (song file or YouTube URL -> chords / melody / tab / MIDI)

### Takeaway
Nearly every open-source end-to-end project found is a thin chain of the same off-the-shelf pieces, yt-dlp -> Demucs (htdemucs/htdemucs_6s) -> Basic Pitch (or CREPE) -> a MIDI-to-tab heuristic (Tayuya, Viterbi fingering, LilyPond/music21), and they are almost all solo hobby repos with 0-40 stars and no ukulele support; the only ukulele-specific audio-to-tab project (OpenUkulele, Sep 2026) is a few weeks old with 0 stars, and the only mature, well-starred components are the building blocks themselves (Basic Pitch 5.6k, Omnizart 2k, Sheet Sage 459, chord-extractor 248, autochord 166).

### Inferences
- The field has converged on a de-facto reference architecture: download (yt-dlp) -> source separation (Demucs) -> frame/note transcription (Basic Pitch; occasionally CREPE/YourMT3+/GAPS) -> symbolic MIDI-to-tab (Tayuya, Viterbi, DP) -> renderer (LilyPond, PyGuitarPro GP5, MusicXML). The transcription stage is almost never fine-tuned for the target instrument.
- TabForge and OpenUkulele are the two repos with any real arrangement logic (Viterbi fingering tuned on GuitarSet; playability constraints with graceful degradation). Both are brand-new (Aug/Sep 2026) and effectively single-author.
- Star counts show the end-to-end projects are not community-maintained; the maintained assets are the components (Basic Pitch, Omnizart, Demucs) and the lead-sheet research artefact (Sheet Sage).
- Licensing pitfalls recur: Sheet Sage weights and madmom are CC BY-NC-SA; chord-extractor is GPL-2.0 (Chordino is GPL); tabforge's best guitar weights are CC BY-NC. A commercial ukulele product would need Apache/MIT components (Basic Pitch, Omnizart, Demucs is MIT) or its own models.

### Gaps
- Exact last-commit dates for audiotab, Ashellas/guitar-tab-generator, TabifyAI and gtrsnipe were not retrieved (not fetched via API).
- No open-source end-to-end project found that accepts a YouTube URL and produces ukulele tab; OpenUkulele requires a local file and TabForge has no YouTube input.
- No issue-tracker content could be read for any of these repos (issue counts only).

## Key question 2: Academic end-to-end tablature / lead-sheet systems (2019-2026) and the difficulties they report

### Takeaway
Academic audio-to-tab has moved from GuitarSet-only CNNs (TabCNN 2019, FretNet 2022) to modular pipelines (TART 2025/26: transcription -> technique MLP -> T5 string/fret -> tab) and playability-aware diffusion (Noise2Fret 2026), with end-to-end tab F1 still only ~54% on clean guitar audio; the consistently cited bottleneck is data (hence SynthTab, GAPS, GOAT) and the string/fret ambiguity that pitch alone cannot resolve.

### Cited Findings
- TabCNN (Wiggins & Kim, ISMIR 2019): CNN on CQT frames predicting fret classes for solo acoustic guitar; multipitch F-measure 0.826; code at github.com/andywiggins/tab-cnn. — [ISMIR 2019 paper](https://archives.ismir.net/ismir2019/paper/000033.pdf)
- FretNet (Cwitkowitz et al., 2022): continuous-valued pitch-contour output layer for polyphonic guitar tab, six-fold CV on GuitarSet; code github.com/cwitkowitz/guitar-transcription-continuous. — [arXiv 2212.03023](https://arxiv.org/pdf/2212.03023)
- SynthTab (ICASSP 2024): "first large-scale synthesized guitar audio dataset with string-accurate tablature annotations", built from DadaGP tabs rendered through commercial virtual instruments (acoustic and electric, 6-string, no tempo changes). — [arXiv 2309.09085](https://arxiv.org/html/2309.09085v3); code [github.com/yongyizang/SynthTab](https://github.com/yongyizang/SynthTab)
- DadaGP: 26,181 GuitarPro songs across 739 genres in GP and token format, enabling tab generation research. ProgGP: 173 progressive-metal GP songs for fine-tuning a Transformer. — [ProgGP arXiv 2307.05328](https://arxiv.org/html/2307.05328)
- GAPS (ISMIR 2024): 14 hours of classical guitar audio-score pairs from 200+ performers with note-level MIDI alignment, plus a benchmark model "achieving state-of-the-art on GuitarSet in supervised and zero-shot settings". — [ResearchGate abstract](https://www.researchgate.net/publication/383216845_GAPS_A_Large_and_Diverse_Classical_Guitar_Dataset_and_Benchmark_Transcription_Model)
- MIDI-to-Tab (Edwards, Riley, Sarmento, Dixon, ISMIR 2024): BERT-style masked language model over MidiTok tokens with string tokens masked, inferring tab from MIDI. — [paper summary](https://www.emergentmind.com/papers/2408.05024)
- Fretting-Transformer (2025): T5 encoder-decoder MIDI -> tablature. — [arXiv 2506.14223](https://arxiv.org/pdf/2506.14223). Follow-up (Jul 2026): explicit note-event tokenisation with pitch-validity constrained decoding; code promised at github.com/MusicGuitarTab/GuitarTab. — [arXiv 2607.26440](https://arxiv.org/html/2607.26440)
- GOAT (ISMIR 2025, Loth, Sarmento, Sarkar, Guo, Barthet, Sandler): 5.9 h of direct-input electric guitar audio paired with GuitarPro tabs including playing techniques; helper code at github.com/JackJamesLoth/GOAT-Dataset, data by request on Zenodo. — [ISMIR 2025 poster](https://ismir2025program.ismir.net/poster_245.html); [arXiv 2509.22655](https://arxiv.org/abs/2509.22655)
- TART v1 (Gupta et al., UC Berkeley, Oct 2025): four stages, "(1) Audio-to-MIDI pitch conversion through a piano transcription model adapted to guitar datasets; (2) MLP-based expressive technique classification; (3) Transformer-based string and fret assignment; and (4) LSTM-based tablature generation"; claims to be "the first to generate detailed tablature with accurate fingerings and expressive labels from guitar audio". — [arXiv 2510.02597](https://arxiv.org/abs/2510.02597)
- TART v2 (Sep 2026, ISMIR 2026 submission): audio-conditioned T5 for string/fret; on GuitarSet, EGDB and noisy variants reports 81.35% audio-to-MIDI F50 (+6.67), 71.8% string-fret Tab F1 (+8.5) and only 54.08% end-to-end Tab F1; no code URL in abstract. — [arXiv 2609.11904](https://arxiv.org/abs/2609.11904)
- Noise2Fret (Simionato & Bigo, Aug 2026, ISMIR 2026): diffusion model over a continuous latent of fret/string targets with five auxiliary losses (pitch-class distance, positional distance, circle-of-fifths distance, string similarity, hand-span feasibility); evaluated on GuitarSet and GOAT; "outperforms baselines while remaining computationally more efficient". — [arXiv 2608.30854](https://arxiv.org/abs/2608.30854)
- "Leveraging Real Electric Guitar Tones and Effects to Improve Robustness in Guitar Tablature Transcription Modeling" (2024) exists specifically because effects/distortion degrade tab models. — [arXiv 2405.14679](https://arxiv.org/pdf/2405.14679)
- Chord recognition: Lardet's "Chord Recognition with Deep Learning" (Dec 2025) reviews ACR; Phan et al. (Feb 2026) use pseudo-labels from 1,072 h of FMA/DALI/MAESTRO audio plus distillation to improve ACR. — [arXiv 2512.22621](https://arxiv.org/pdf/2512.22621); [arXiv 2602.19778](https://arxiv.org/abs/2602.19778)
- Foundation models: MuQ (Jan 2025) was introduced to reduce the cost of MERT's Encodec targets; a 2025 survey reports "fingerprints extracted with music foundation models (e.g., MuQ, MERT) consistently outperform models trained from scratch". — [MuQ arXiv 2501.01108](https://arxiv.org/pdf/2501.01108); [Foundation model for music understanding 2508.01178](https://arxiv.org/pdf/2508.01178)
- Ukulele-specific academic work is essentially one group: Phithak, Angskun & Angskun, "A machine learning-based approach for strumming pattern recognition from ukulele songs", Information (Tokyo) vol. 18 no. 2, 2015, pp. 705-718; strum types d-, du, -u, xu; strum-type predictor F-measure 82.6% (another abstract of the same work says 84.94%); patterns recognised correctly on all 10 test songs. — [ProQuest record](https://www.proquest.com/openview/e55f121cf94bb00eb34e7ec8ba34ec7b/1?pq-origsite=gscholar&cbl=936334); [ResearchGate](https://www.researchgate.net/publication/282060679_A_machine_learning-based_approach_for_strumming_pattern_recognition_from_ukulele_songs)

### Inferences
- The gap between 81% note F-score and 54% end-to-end tab F1 in TART shows that string/fret assignment, not pitch detection, is now the dominant error source for tab; this is directly relevant for ukulele, where the re-entrant high-G string makes pitch-to-string mapping even more ambiguous.
- Datasets are all guitar (GuitarSet, EGDB, GAPS, GOAT, SynthTab/DadaGP). No ukulele audio-tab dataset was found; a new project would have to synthesise one (SynthTab-style from GP files with a uke tuning) or rely on guitar-trained models plus a ukulele constraint solver.
- Playability losses (Noise2Fret) and masked-LM MIDI-to-tab are the academic answers to "which fingering"; they are symbolic-side and could be re-trained for 4 strings cheaply since they do not need audio.

### Gaps
- Could not confirm public code for TART, Noise2Fret, or the WASPAA rhythmic-pattern paper (abstract pages list none).
- Full text of the 2015 ukulele strumming paper (features/classifier) is paywalled; only two slightly conflicting F-measure figures (82.6% vs 84.94%) appear in abstracts.
- No 2024-2026 ISMIR paper on ukulele transcription or arrangement was found.

## Key question 3: Chord-only and commercial tools with YouTube input (Chordify, Moises, Ultimate Guitar, Chord ai, Songsterr, Klangio, AnthemScore, Capo, Riffstation, Soundslice)

### Takeaway
Commercial tools split cleanly into chord-timeline products (Chordify, Moises, Chord ai, Ultimate Guitar "AI chords", ChordU, Chord Detector) that accept YouTube links and output beat-aligned chord labels with diagrams for guitar/piano/ukulele, and note-level transcribers (Songsterr AI, Klangio Guitar2Tabs/Transcription Studio, Songscription, Audio2Guitar, AnthemScore) that output GP5/MusicXML/MIDI; none of them outputs a detected strumming pattern, and the chord tools self-report 75-90% accuracy at best.

### Cited Findings
- Chordify: originated as a Utrecht University research project (Dept. of Information and Computing Sciences), launched at Eurosonic 2013; "accuracy of 75-90%, depending on the style of the music and the sound quality of the recording". — [Utrecht University news](https://www.uu.nl/en/news/utrecht-university-and-chordify-introduce-revolutionary-interactive-application); ISMIR 2012 LBD "Chordify: chord transcription for the masses". — [ISMIR 2012 LBD PDF](https://ismir2012.ismir.net/event/papers/LBD2.pdf)
- Chordify's current description: audio -> spectrogram -> "a chord network that identifies harmonic structures and a beat network that determines rhythmic timing", with YouTube/SoundCloud/upload input. — [Techleap profile](https://techleap.nl/blog/chordify-striking-the-right-note-in-music-education-and-ai-innovation)
- Chordify (Guitar Chalk review, 2026-04-19): YouTube primary input, audio upload for premium; outputs chord sheet, diagrams, real-time sync, transpose, capo, tempo, loop, MIDI export (premium); "no tablature or strumming patterns provided"; users report "chord changes out of place"; free tier 3 songs/day; $4 basic / $8 premium monthly. — [Guitar Chalk](https://www.guitarchalk.com/chordify-review/)
- Chordify on strumming: "Chordify is not able to accurately detect strumming patterns, as this is near-impossible to detect accurately with algorithms and unlikely to be added in the future"; the paid "Song Lessons" feature instead shows a human-authored strum (down/up/rest) on one chord per section. — [Chordify support article (search snippet; page itself returned 403)](https://support.chordify.net/hc/en-us/articles/360019489618-Does-Chordify-show-the-strumming-patterns); [Song Lessons](https://support.chordify.net/hc/en-us/articles/33951891429917-What-are-Song-Lessons)
- Moises Chord Finder: real-time chords synced to music, Easy/Medium/Advanced voicing levels, capo mode, editable timeline with bars and beats, export to chord sheet with lyrics and sections; instrument profiles include Ukulele. Advanced chord detection (incl. extended jazz chords) launched 2023-07-25; free users get the first minute. No tab output; no strumming output. — [Moises Chord Finder](https://moises.ai/features/chord-finder/); [Moises blog 2023](https://moises.ai/blog/latest/advanced-chord-detection/); [Moises Oct 2025 release notes](https://moises.ai/blog/latest/improvements-latest-releases/)
- Ultimate Guitar "AI chords" (help article dated 2026-05-22): paste a YouTube link (max 15 min) in the app; "several chord variations" returned in <= 10 minutes; 10 attempts per 24 h; chords only, no strumming or tab; thumbs up/down feedback loop. — [UG help](https://help.ultimate-guitar.com/en/articles/14771579-mobile-what-are-the-ai-chords)
- Songsterr AI (heise, 2025-04-17): YouTube or own recordings -> guitar, bass, drum (and vocal) tabs; test on "Enter Sandman" and "Sweet Child O' Mine" matched published tabs; misses palm muting and slides, sometimes confuses separate guitar tracks, "invented notes still fit"; performance "independent of guitar tone (distorted vs. clean)"; free 20-second clips, ~$10/month unlimited; Plus tier capped at 50 AI tabs/month. — [heise](https://www.heise.de/en/news/Songsterr-uses-AI-to-create-fairly-accurate-guitar-tabs-from-your-own-recordings-10356152.html); [Songsterr generate page](https://www.songsterr.com/new)
- Klangio Guitar2Tabs: inputs live recording, upload, YouTube; outputs tabs, MIDI, MusicXML, GP; ticket pricing, ~20 s free demo; fingerpicking vs strumming mode selector; reviews say notes are right but "laid out in a way that doesn't reflect how you'd actually play"; bend/slide detection inconsistent; app-store ratings 2.9-3.4/5 with accuracy the main complaint; Trustpilot 3.5-4/5. Klangio Transcription Studio lists ukulele among supported instruments. — [Songscription comparison (vendor blog)](https://www.songscription.ai/blog/best-ai-guitar-tab-generators); [Klangio review](https://agent-finder.co/reviews/klangio); [Trustpilot](https://ie.trustpilot.com/review/klang.io); [Klangio Studio](https://klang.io/transcription-studio/)
- Songscription (vendor, 2026-06): upload/YouTube/live -> GP, MusicXML, MIDI, PDF with piano-roll editor; 30-second free preview; admits "clean solo line transcribes far better than a dense chord progression buried under distortion". — [Songscription blog](https://www.songscription.ai/blog/best-ai-guitar-tab-generators)
- AnthemScore (Lunaverus): one-time purchase, Win/Mac/Linux, 30-day trial; "does not make guitar tablature, has no drum mode, and does not split a recording into separate parts"; user review: "Notes are rhythmically all over the place, with lots of extra notes"; doubled notes on mandolin/12-string. — [Songscription alternatives post (vendor)](https://www.songscription.ai/blog/anthemscore-alternatives); [SourceForge reviews](https://sourceforge.net/software/product/AnthemScore/)
- Chord ai app: detects chords from device audio/streams/live mic, shows finger positions for guitar, piano and ukulele; reviewers praise complex-chord detection (maj7, dim, altered dominants) but note drops on jazz/avant-garde. — [Google Play](https://play.google.com/store/apps/details?id=com.chordai&hl=en_US); [Chord ai review](https://ai-review.com/audio-editing/chord-ai/)
- ChordU: markets "extremely high accuracy" deep-learning chords; user reviews say "nothing gave accurate results". — [Google Play](https://play.google.com/store/apps/details?id=com.chordu.chorduapp)
- Riffstation (Sonic Ladder/Fender): auto-detected maj/min/7th chords at "approximately 85% accuracy"; iOS/web discontinued May 2018, all distribution ended early 2019. A separate open-source "Capo" (rickraph/Capo on GitHub, cross-platform) is a Riffstation clone, unrelated to the commercial Mac app of the same name. — [RoaringApps](https://roaringapps.com/app/riffstation); [rickraph/Capo](https://github.com/rickraph/Capo)
- Soundslice: does not transcribe audio to notation; its AI is OMR (scan score) plus Aug 2025 audio/notation auto-alignment. — [Soundslice blog](https://www.soundslice.com/blog/290/new-auto-align-audio-with-notation/)
- Generic chord-detection ceiling cited by a keyboard forum thread on Chord AI: "the level of chord detection accuracy for even the very best products is in the low/mid 70% range" (forum opinion, not a benchmark). — [MusicPlayer forum (page 403 on fetch; from search snippet)](https://forums.musicplayer.com/topic/180906-chord-ai-app-for-android-and-ios-impressive-chord-detection/)
- Ukulele players (Ukulele Underground, Feb 2015) on Riffstation/YouTube chord detection: "pretty accurate" for obscure songs, but chord changes "don't necessarily happen right on the beat" and it sometimes "adds a chord that doesn't necessarily belong". — [Ukulele Underground thread](https://forum.ukuleleunderground.com/threads/chord-detection-app.104579/)

### Inferences
- Commercial chord tools converge on the same two-network design Chordify describes (chord net + beat net), and they all hide complexity behind "Easy/Medium/Advanced" voicing levels rather than exposing the raw chord vocabulary. Easy mode for ukulele is essentially triad reduction plus capo/transpose, which is cheap to replicate.
- The commercial note-level transcribers (Songsterr, Klangio) accept YouTube input but are guitar/bass/drum centred; ukulele appears only as an instrument label in Klangio Studio, not as a dedicated arrangement mode.
- Chordify's explicit refusal to attempt strumming detection, combined with its human-authored Song Lessons strum, is strong market evidence that automatic strum output is an unfilled niche.

### Gaps
- The Chordify ISMIR 2012 PDF could not be parsed; the HarmTrace/NNLS-chroma lineage of early Chordify is not confirmed from a fetched source.
- No public architecture details for Moises, Songsterr AI, UG AI chords, or Klangio models.
- Yalp was not found in results; its current status is unknown.
- Reddit threads were inaccessible (crawler blocked), so no r/Guitar or r/ukulele quotes could be captured.

## Key question 4: Which systems output strumming patterns, and how?

### Takeaway
No shipping product or open-source pipeline found outputs a detected strumming pattern; strum patterns on UkuTabs/ukulele-tabs.com and Chordify Song Lessons are human-authored, while the only automatic approaches are research (2015 Thai ukulele strum-type classifier, Murgul et al. ISMIR 2025 CRNN strum-direction+chord on acoustic guitar, Lukoianov & Klapuri WASPAA 2025 MERT-based strum detection on separated guitar stems mapped to an expert pattern vocabulary) with no public code located.

### Cited Findings
- Chordify: "not able to accurately detect strumming patterns ... near-impossible to detect accurately with algorithms and unlikely to be added in the future". — [Chordify support](https://support.chordify.net/hc/en-us/articles/360019489618-Does-Chordify-show-the-strumming-patterns)
- UkuTabs app: "suggested strumming pattern with a hear-it button for over 20,000 songs" — user/editor-submitted, not detected. — [UkuTabs on Google Play](https://play.google.com/store/apps/details?id=com.ukutabs.songs&hl=en_US)
- ukulele-tabs.com hosts a strumming-patterns reference page (human-written). — [ukulele-tabs.com](https://www.ukulele-tabs.com/strumming-patterns.html)
- Guitar Chalk on Chordify: "No tablature or strumming patterns provided". — [Guitar Chalk](https://www.guitarchalk.com/chordify-review/)
- Songsterr AI "cannot visually assess fingering technique or strumming mechanics". — [heise](https://www.heise.de/en/news/Songsterr-uses-AI-to-create-fairly-accurate-guitar-tabs-from-your-own-recordings-10356152.html)
- Murgul, Schimper & Heizmann, "Joint Transcription of Acoustic Guitar Strumming Directions and Chords" (ISMIR 2025): CRNN detects strum events, classifies up/down direction and the chord from microphone audio; trained on 90 min real recordings labelled with an ESP32 smartwatch motion sensor plus 4 h synthetic strumming audio; hybrid real+synthetic training best; prior work on the pickup signal reached ~98% strum-detection F1; no code listed. — [arXiv 2508.07973](https://arxiv.org/abs/2508.07973)
- Lukoianov & Klapuri, "Transcribing Rhythmic Patterns of the Guitar Track in Polyphonic Music" (WASPAA 2025, arXiv 2025-10-07): (1) approximate stem separation, (2) per-strum detection with a MERT backbone, (3) decoding to an "expert-curated vocabulary" of rhythmic patterns; dataset of 410 popular songs with musician-transcribed patterns and re-recorded covers; custom accuracy+readability metrics; CC BY-NC-ND; no code mentioned. — [arXiv 2510.05756](https://arxiv.org/abs/2510.05756)
- Phithak et al. 2015 (ukulele): predicts strum types d-, du, -u, xu per beat then matches to a pattern; F-measure 82.6% (or 84.94% per the other abstract); 10 test songs. — [ProQuest](https://www.proquest.com/openview/e55f121cf94bb00eb34e7ec8ba34ec7b/1?pq-origsite=gscholar&cbl=936334); [ResearchGate 2014 version](https://www.researchgate.net/publication/269229660_Strumming_pattern_recognition_from_Ukulele_songs)
- Klangio Guitar2Tabs offers a user-selected "fingerpicking vs strumming" mode (an input hint, not a detected output). — [Songscription/Klangio listing](https://www.songscription.ai/blog/best-ai-guitar-tab-generators)

### Inferences
- The 2025 WASPAA design (separate guitar stem -> MERT strum onsets -> snap to a small curated pattern vocabulary) is the most practical template for ukulele: a pattern vocabulary (D-DU-UDU, island strum, etc.) is small, and decoding to the nearest vocabulary entry sidesteps the "near-impossible" exact-strum problem Chordify cites.
- Ukulele-tabs-style human strum patterns per song are a potential weak-supervision source (song -> pattern label) analogous to how Sheet Sage used HookTheory.
- Strum direction (up/down) from a full mix is far harder than from a close mic; a new project should probably output a readable pattern that fits the detected onsets rather than claim true up/down direction.

### Gaps
- No public implementation of any of the three strumming papers was found.
- No dataset of ukulele strums with audio was found; the 2015 study's data size beyond "10 test songs" is unknown.

## Key question 5: Lessons — shared architecture of the better systems, failure modes on rock/distorted guitar, and remaining gaps for a new ukulele project

### Takeaway
The better systems (Sheet Sage, TabForge, TART, Songsterr AI) share a separation -> beat/meter grid -> note or chord transcription -> symbolic arrangement with explicit playability constraints -> GP5/MusicXML render chain; they fail on dense distorted mixes, beat/downbeat doubling, wrong string/fret placement, and technique (palm mute, slide) detection; the open gaps most relevant to a ukulele project are automatic strumming patterns, deciding riff vs. strummed-chord sections, and ukulele-specific (re-entrant, 4-string) arrangement with difficulty tiers.

### Cited Findings
Shared architecture:
- Sheet Sage: madmom beat/downbeat -> melody model (Jukebox features optional) -> chord model -> LilyPond + MIDI. — [GitHub](https://github.com/chrisdonahue/sheetsage)
- TabForge: Demucs -> per-instrument transcriber (Basic Pitch / GAPS / YourMT3+) -> beat-grid ensemble with glitch auto-correction -> key detection -> Viterbi fingering with penalties for fret height, string choice and hand movement -> GP5/MusicXML. — [GitHub](https://github.com/rayBastard/tabforge)
- TART: audio-to-MIDI -> technique classifier -> T5 string/fret -> tab. — [arXiv 2609.11904](https://arxiv.org/abs/2609.11904)
- Chordify: chord network + beat network over a spectrogram. — [Techleap](https://techleap.nl/blog/chordify-striking-the-right-note-in-music-education-and-ai-innovation)
- OpenUkulele: quantise -> arrange (easy/hard) -> DP fingering -> validate -> degrade gracefully. — [GitHub](https://github.com/xin-pu/OpenUkulele)

Failure modes (documented):
- Distortion/density: Songscription "a clean solo line transcribes far better than a dense chord progression buried under distortion" and "heavily distorted electric tones are the hardest for any transcription model" (vendor). — [Songscription](https://www.songscription.ai/blog/best-ai-guitar-tab-generators)
- tab-gener8or: struggles with "very fast, distorted, or complex polyphonic passages"; IrdiZ: chord detection ~25% F1 and distorted guitar needs attack-transient analysis. — [tab-gener8or](https://github.com/mgd1984/tab-gener8or); [IrdiZ/guitar-tabs](https://github.com/IrdiZ/guitar-tabs)
- Songsterr AI misses palm muting and slides, confuses separate guitar tracks, mis-places positions even when notes are right; but heise found accuracy "independent of guitar tone (distorted vs. clean)". — [heise](https://www.heise.de/en/news/Songsterr-uses-AI-to-create-fairly-accurate-guitar-tabs-from-your-own-recordings-10356152.html)
- Klangio: notes right but layout unplayable; "missing chords or picking up vocals instead" (app-store reviews). — [agent-finder review](https://agent-finder.co/reviews/klangio); [Google Play](https://play.google.com/store/apps/details?id=com.klangio.guitar2tabs&hl=en_US)
- Sheet Sage: tempo doubling/halving and unreliable downbeats; tuned for ~24 s windows. — [GitHub](https://github.com/chrisdonahue/sheetsage)
- TabForge: guitar polyphonic F1 only 0.41 in a full mix; single tempo grid per track; synth pads transcribe poorly. — [GitHub](https://github.com/rayBastard/tabforge)
- AnthemScore: no tab, no separation, rhythm "all over the place", doubled notes on mandolin/12-string. — [Songscription alternatives post](https://www.songscription.ai/blog/anthemscore-alternatives)
- Riffstation/Chordify on ukulele forums: chord changes off the beat and spurious extra chords. — [Ukulele Underground](https://forum.ukuleleunderground.com/threads/chord-detection-app.104579/); [Guitar Chalk](https://www.guitarchalk.com/chordify-review/)
- Research: a 2024 paper exists solely to add "real electric guitar tones and effects" to improve tab-model robustness, and TART evaluates on "Noisy GuitarSet / Noisy EGDB" augmentations. — [arXiv 2405.14679](https://arxiv.org/pdf/2405.14679); [arXiv 2609.11904](https://arxiv.org/abs/2609.11904)
- Chord-voicing choice as its own research problem: "Guitar Chord Diagram Suggestion for Western Popular Music" (2024). — [arXiv 2407.14260](https://arxiv.org/pdf/2407.14260)

Ukulele-specific state:
- Only OpenUkulele implements ukulele arrangement rules (high-G re-entrant, 15 frets, span and barre constraints, easy/hard tiers) and only TabForge lists a ukulele tuning preset; neither takes YouTube or outputs strums. — [OpenUkulele](https://github.com/xin-pu/OpenUkulele); [TabForge](https://github.com/rayBastard/tabforge)
- Commercial chord apps (Moises, Chord ai, Chord it, Muse Forge) show ukulele chord diagrams but no arrangement or strum. — [Moises](https://moises.ai/features/chord-finder/); [Chord ai](https://play.google.com/store/apps/details?id=com.chordai&hl=en_US); [Muse Forge](https://forge.dwave.cc/en-US/blog/1359)

### Inferences
- Architecture lesson: keep the audio models generic (Demucs + Basic Pitch/Harmonica for notes, a modern ACR for chords, a beat/downbeat tracker) and put the instrument-specific intelligence in the symbolic layer (constraint solver or MIDI-to-tab LM retrained for 4-string re-entrant tuning, difficulty tiers, graceful degradation). This is what both OpenUkulele and TabForge do and what TART's modularity implies.
- Beat/downbeat quality is a first-order risk (Sheet Sage, TabForge, Chordify forum complaints all cite it); a ukulele chord/strum sheet is unusable if bars are misaligned, so invest in a robust downbeat tracker (madmom is CC BY-NC-SA; alternatives needed for commercial use).
- Riff vs. chord discrimination is not addressed by any system found: the note transcribers tab everything, and the chord tools label everything as chords. A section classifier on the separated guitar stem (polyphony density + onset regularity + MERT embeddings) would be new.
- Strumming is the clearest gap: the market leader says it is impossible, yet two 2025 papers show a feasible route (separated stem -> strum onset model -> snap to curated vocabulary). For ukulele, a vocabulary of ~20 patterns plus per-section pattern decoding is a tractable, differentiated feature.
- Licensing: Basic Pitch (Apache), Omnizart (MIT), Demucs (MIT), TabForge/OpenUkulele (MIT) are safe; avoid Chordino/chord-extractor (GPL), madmom (CC BY-NC-SA), Sheet Sage weights (CC BY-NC-SA), MuScriptor weights (CC BY-NC) if commercial use is contemplated.

### Gaps
- No issue-tracker text was readable for any repo, so "issue tracker says" evidence is limited to README self-reports and third-party reviews.
- No quantitative benchmark of any commercial tool on rock/distorted material exists in the sources found; heise's "independent of tone" claim for Songsterr conflicts with vendor caveats and is anecdotal.
- No source on how commercial tools decide riff vs. chord sections.
